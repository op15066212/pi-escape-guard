# pi-escape-guard

**主要目的：调用工具前拦住写转义的人。** 事后还原是补漏，不是主路。

要写一段中文却写成一段转义序列，通常不是因为不知道能直写，而是为了绕开某一层转义：
写转义、包一层脚本、脚本里再写转义，越绕越深。这个插件在工具真的执行之前拒掉它，
并告诉写的人这段本该是什么字。

## 一个口

| 位置 | 判据 | 动作 | 反例 |
| --- | --- | --- | --- |
| `tool_call` | 入参里有 ≥ `block.min` 个**连续**转义 | 拒绝执行，`reason` 里给出它本该是什么 | 一段参数里连写三个以上 `\u` 开头的转义 |

只有这一个钩子。使用者在 2026-11-26 把范围收到「只保留 `tool_call` 与拒绝执行」：
原来还有 `tool_result` / `message_end` 两条还原钩子，以及 `/escape-guard` 观察命令，全部删除。

配置**每次调用现读**：改完文件下一次工具调用就生效。
它不报「还原过几次」——那不是判据。能自证的是「现在这条门槛，遇到这三种输入会怎么做」，
任何时刻可跑，不依赖历史。

## 为什么门槛算「连续」而不是「总共」

正则字符类 `[\u4e00-\u9fff]` 是两个转义，中间隔着 `-`，那是必要写法，写代码绕不开。
所以判据按「一段里连续几个」算，默认 3。

测试里钉着这条边界：`min=2` 时两个连续转义要拦，正则字符类那种（不连续）仍然放行。
这条边界不是调出来的，是「必要写法」与「偷懒写法」的分界。

## 判据

| # | 命题 | 门槛从哪来 | 反例 |
| --- | --- | --- | --- |
| S0 | 调用工具前，入参里有成串转义就拒 | `block.on` / `block.min`，默认开 / 3 | 一段参数里连写三个转义；而正则字符类那种两个不连续的，该放 |

**只有这一条。** 拦截要问的不是「这段该不该还原」，而是「你写这段参数时，本来可以直接写中文吗」。
所以不看位置：围栏、反引号、赋值行都不例外。唯一让步是门槛。

## 元理论

依赖类型理论是唯一判法。一条规则就是一个类型；说它成立，就要指得出住在这个类型里的居民。
四件缺一不算规则：

| 件 | 是什么 | 缺了会怎样 | 反例 |
| --- | --- | --- | --- |
| 形成 | 这个词落到盘上，对应哪个可查的东西 | 规则悬空，改代码它不跟着变 | 文档写「默认 3」，代码是 4 |
| 引入 | 一条命令加它的期望退出码 | 说成立但验不了 | 「按需检查」 |
| 消去 | 换第二个入口算一遍，得同一个答案 | 两处各算一遍，没有比较物 | 同一段在两个入口给出两个判决 |
| 反例 | 一个具体输入，喂进去这句话就假 | 只有好样本会绿，判据是恒真 | 「视情况」 |

`src/meta.ts` 的 `RULES` 是这套说法的居民：只剩 S0 一条。
「形成」格里的默认值取自 `src/config.ts` 的 `DEFAULTS`，不手写第二份——
改默认值时文本跟着变，于是描述与实现不会分成两件事。

## 配置

一个文件：插件目录下的 `pi-escape-guard.json`，首次启动写入默认值。
用 `ESC_GUARD_CONFIG` 指向别处。改完**下一次工具调用**就生效——配置在 `tool_call` 里现读，
不缓存、不等 `session_start`。

全部键与默认值见 `SETTINGS.md`。

## 怎么验

```
npm run verify                  # 一条命令跑完下面全部
node scripts/gate.mjs           # 总闸：glob 发现 check-*.mjs，不靠登记
npm test                        # 单元测试
node verify-dtt.mjs             # 元理论判据：四件齐、引入可跑
```

总闸给每条判据跑两步：先 `--selftest`（证明它会红），再正常模式（证明现在的盘面没红）。
selftest 红了就不跑正常模式——判据本身坏了，它给的「0 处对不上」没有意义。

反例：往 `scripts/` 塞一个返回 1 的临时判据脚本，总闸必须 rc=1 并点名它。

### 四个检查脚本

| 脚本 | 挡什么 | 反例 |
| --- | --- | --- |
| `scripts/check-doc-accuracy.mjs` | 文档里的配置键与路径，盘上必须真有 | 文档写已删的键 `strict`；或 GENERATED 名单里塞一个 .gitignore 没点名的名字 |
| `scripts/check-mirror.mjs` | 两个仓的 `keysIn` / `pathsIn` 行为必须一致 | 一边修掉误报、另一边没跟着改 |
| `scripts/check-rc-pipe.mjs` | 报退出码的那一行不许有管道 | 管道之后取 `$?` |
| `scripts/check-main-guard.mjs` | 有导出的脚本，「直接跑」与「被 import」两个方向都要对 | 把 `import.meta.main` 判据删掉，让被 import 时也执行主流程 |

## 它不做什么

实现里删掉的两样：观测计数（`stats` / `report`）与首见重复记账（`seen`）。
它们不改变任何一个动作——不改变动作的账本，时间一长只会变成第二个真相。

## 排错

| 症状 | 先看 |
| --- | --- |
| 该拦的没拦 | `block.on` 是否开、`block.min` 是否被调大；再看入参是不是「不连续」 |
| 拦错了（正则字符类被拒） | `block.min`：`min=2` 时两个连续转义就会拦，那会误伤 |
| 改了配置没生效 | 配置文件是不是 `ESC_GUARD_CONFIG` 指的那份；配置每次调用现读，不需要重启 |

签字与未验证项见 `SIGN-OFF-DTT.md` 与 `SIGN-OFF.md`。
