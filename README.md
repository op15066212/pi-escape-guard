# pi-escape-guard

对话记录里出现字面 `\u4f60\u53ef\u4ee5` 这种东西（本该是「你可以」）。一旦落盘，模型每轮都读到它，
就学着照抄，越滚越多。这个扩展在**两个源头槽位**上把它还原成它代表的字，然后在代码上下文里一律不碰。

## 查看当前门槛

```text
/escape-guard
```

四行，拿**当前配置**现场跑三种样例：

```text
threshold 3   开关 开
该还原   还原 25 字符
不够数   不动
代码里   不动
```

第三种是围栏内的正则 `/[\u4e00-\u9fff]/`——它不该被动，动了代码就坏。

**为什么不记「还原过几次」**：那个数字不改变任何动作，属于观测（R12 删过 stats）。
能自证的是「现在这条门槛遇到这三种输入会怎么做」，任何时刻可跑，不依赖历史。

## 元理论：依赖类型理论（唯一）

`Γ ⊢ 规则 : Prop`。一条规则就是一个类型；说它成立 = 指得出住在这个类型里的居民。没有居民就不成立，写 `sorry`，不写「显然」。

四件缺一不算规则：

| 件 | 在这份文档里是什么 | 反例 |
| --- | --- | --- |
| 形成 | 命题里每个词都能落到盘上可查的东西（`pi-escape-guard.json` 的四个键、C1–C4、`test/fixtures/` 里的坏样本） | 「必要时生效」——盘上查不到它在哪生效 |
| 引入 | 一条命令 + 它该返回的 rc | 只写「已测」，不写退出码 |
| 消去 | 换第二个入口算一遍，得同一个答案 | 两个入口读的是同一处，只算一条 |
| 反例 | 一个具体输入，喂进去这条规则就为假 | 反例格里写「视情况」 |

判法：`node verify-dtt.mjs`（rc=0）；坏样本 `node verify-dtt.mjs --selftest`（五个坏样本全红）；指纹 `node verify-dtt.mjs --fingerprint`（sha256，与 `SIGN-OFF-DTT.md` 里的一致才算签过）。

这套判法自己的反例：文档长得像规则、每格都填着形容词。`verify-dtt.mjs` 判反例格是否为空、判点名的脚本在不在盘上——形容词能过格，脚本不在盘上过不了。
## 一屏

- 装在 pi 里，自动生效，不需要命令。
- S1 工具结果、S2 助手正文：还原。S3 发给模型前：只看不动。S4 已落盘的记录：没有钩子。
- 代码里不动：围栏、行内 code、赋值行、紧邻引号的字面量、双重转义、少于 3 个转义的孤立段。
- 解的文本里混进非中文（比如 `\u0024`）也不动——那多半是正则，不是污染。

## 判据只有三条

| 判据 | 说的是 | 坏样本 |
| --- | --- | --- |
| C1 | 解出来不含字面转义 | `\u005c\u0075\u0034\u0066\u0036\u0030` 解出 `\u4f60` |
| C2 | 解出来全是 CJK（含空白、全角标点） | `\u0024\u0024\u0024` 解出 `$$$` |
| C3 | 不在代码上下文 | `const s = "…"`、``` 围栏、`名字=…` |
| C4 | 策略阈值：至少 3 个转义 | 孤立 `\u4f60` 不动 |

**C3 是四条里唯一会误伤真污染的**：它靠位置判，位置只是代理。实测代价写在 DESIGN §4。

## 开关

配置文件 `pi-escape-guard.json`（首次运行自动生成）。只有两个键：

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `on` | true | 总开关。关掉后 `settle()` 直接返回原文本 |
| `threshold` | 3 | 一段里几个转义算「成段」。写 0 或非数字会回落成 3 |

别照着旧版填九个键——`strict` / `ratio` / `skipFixtures` / `toolResult` / `assistant` / `provider` / `report` 都不读，填了不报错也不生效。判据：`node scripts/check-doc-accuracy.mjs` → rc=0。
npm test                      # 判据、位置、记账、接线、钩子五组；条数以它的输出为准，这里不抄数
node bin/mutate.mjs           # 变异巡检：15 个变异，全部抓住，0 存活、0 锚点失效
node bin/all.mjs              # 88 个 jsonl 全量：points ≈55, ratio 1, failFiles 9
```

`failFiles 9` 不是失败，是**交还清单**：那 9 个文件里有 175 段「看着像污染但解出不是纯汉字」，
判据拒绝，需要人看一眼。它红着才说明判据没被拆。

角色检查（role）由 `verdict.ts` 的 `validMessage` 判。这一条曾经没有测试，`bin/mutate.mjs --unique` 一跑就现形——删掉 role 校验，全套测试照样绿。
role 检查守的不是还原动作，是**记账**——`note()` 在 `validMessage` 兜底之前跑，所以 user 消息也会被写进 stats 与 seen。
这就是「判等价必须构造出可区分输入」：我第一眼读代码，以为它被第二道检查完全覆盖。

## 实现里删掉的两样

- **多层 JSON 解包**：88 个文件里 12655 段 double-escaped 全是文件层的，内容层没有第二层。多层解包没有样本能验，等于未验证的代码，不写。
- 判据 `unit-mismatch`：`JSON.parse` 保证每个 `\uXXXX` 产出一个码元，这条判据恒真——恒真的判据不给信息。

两条都记在 DESIGN §10。
